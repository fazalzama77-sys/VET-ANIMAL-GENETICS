How to use these sheets

  1. Print them. Open a sheet, press Print, set Margins → None and tick Background graphics, then Save as PDF or print on A4. Each sheet comes out at exactly 6 pages.
  2. Sweep in order. Page 1 always carries the unit map and the ★ highest-yield list — read that first and you already know where the marks are.
  3. Colour is information. Red boxes are examiner's traps, amber are mnemonics, green are gold-standard lines to quote verbatim, purple explain the why.
  4. The last page of every sheet is a two- or three-column objective ammunition dump plus subjective attack plans — the skeleton of each likely long question. Read that page alone the night before.
  5. Formula strips (the monospaced blue bars) are the ones worth writing out from memory once each — everything numerical in the paper comes from them.
